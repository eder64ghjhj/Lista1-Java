# ☕ Lista 1 — Exercícios Java: Operadores e Cálculos Básicos

Primeira lista de exercícios em Java desenvolvida na Faculdade Flamingo (1° Semestre). Foco em operadores aritméticos, entrada e saída de dados e cálculos matemáticos básicos.

- Cálculo de soma, divisão e média

- Número ao quadrado
